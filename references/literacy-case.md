# 案例：幼儿识字任务课件

老师投屏带中班复习，沿用已有超级飞侠PPT的方向，经历入口、地图、分组识字、图片与读音、奖励和词语配对，打包HTML与本地assets。

| 实际问题 | 可迁移判断 |
| --- | --- |
| 说明、标签和边框堆叠 | 学习画面只放本次需要的信息，教师说明独立呈现 |
| 背景贴字冒充对应图 | 教学图表达字义或情境，文字不代替图像 |
| 缩略图压扁、放大模糊 | 检查比例、每格像素与主图分辨率 |
| 浅底白色导航、完成页看不清 | 检查所有页面与按钮状态对比度 |
| 拼音、重复字与图片争空间 | 减少重复信息，提示按需揭晓 |
| 奖励移动到一半换关 | 播放完整后停留，老师决定继续 |
| 系统朗读机械且跨设备不一致 | 先试听再生成本地音频 |
| 口头“49”与实际48个条目不符 | 从材料核对数量，不能沿用标题数字 |
| 命名混乱、学校电脑使用麻烦 | 明确入口，相对资源路径，检查解压与离线打开 |

超级飞侠、拍拍探员、蓝色大厅、3D软萌图、单字卡和地图勋章属于案例选择，不作为通用默认。角色可用用户提供的可用素材或原创设计；计划公开分发时确认素材使用范围，不把案例IP嵌入通用模板。

一年级应区分会认会写，加入词语与语境；其他学科根据目标重新选互动，不能都改成“字卡 + 配图”。
